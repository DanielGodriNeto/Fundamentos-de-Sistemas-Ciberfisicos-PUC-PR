# 01 · Sistemas de numeração

Um sistema de numeração posicional representa valores com **símbolos** e uma **base** `b`. Cada posição vale uma potência de `b`.

| Sistema | Base | Símbolos |
|---|---|---|
| Decimal | 10 | 0–9 |
| Binário | 2 | 0, 1 |
| Octal | 8 | 0–7 |
| Hexadecimal | 16 | 0–9, A–F |

## Valor posicional
`1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8 + 0 + 2 + 1 = 11₁₀`

## Por que binário?
Circuitos digitais têm dois estados estáveis (tensão alta/baixa, ligado/desligado), então 0 e 1 são simples e confiáveis de implementar.

## Unidades
- **bit**: 0 ou 1
- **byte**: 8 bits (256 valores, 0–255)
- n bits representam 2ⁿ valores distintos
